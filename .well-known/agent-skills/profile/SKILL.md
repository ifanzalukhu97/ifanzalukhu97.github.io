Look up Ifan Jaya Suswanto Zalukhu's professional profile: current role, areas of expertise, and links to his professional presences (LinkedIn, GitHub, Dev.to, Medium, AWS Community Builder profile).

## How to use

Fetch the following URL as plain text:

```
https://www.ifanzalukhu97.com/llms.txt
```

This is a static `llms.txt` file (per the llmstxt.org convention) maintained at the site root. It contains a short bio, key areas of expertise (C#/.NET Core, AWS, Azure, AI/LLM integration, n8n automation, Docker, engineering leadership), a list of links (personal website, LinkedIn, GitHub, Dev.to, Medium, AWS Community Builder profile), a list of recent slide decks, and a list of certifications/badge profiles.

No authentication, query parameters, or request body is required — a single `GET` returns the full document.
