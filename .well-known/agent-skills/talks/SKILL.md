# Talks

List Ifan Jaya Suswanto Zalukhu's conference talks and slide decks, with title, event, date, and a link to the standalone slide deck.

## How to use

This data isn't served from a dedicated API — it's rendered directly on the homepage's "Recent Slides" section:

```
https://www.ifanzalukhu97.com/
```

The homepage lists each talk (title, event, date) with a link to its standalone HTML slide deck under `/slides/`. The same information is also available in summarized form in the "Slides" section of:

```
https://www.ifanzalukhu97.com/llms.txt
```

There is no separate JSON endpoint for talks — an agent should read the homepage's slide listing or `llms.txt` directly rather than expect a dedicated API response.
